# Upcoming View

The **Upcoming** view helps you organize tasks across multiple days. Unlike views focused on doing work (like the Today View or project views), the Upcoming looks ahead so you can arrange tasks across future days, see how work is distributed over time, and integrate calendar events and recurring tasks.

## What the Upcoming Shows

The Upcoming displays a rolling window of days starting today: 15 days on desktop and 5 on phones, with more days loading as you scroll. Overdue tasks appear in a column before today. For each day, you see:

- **Tasks planned for that day** — Tasks you've assigned to that date
- **Planned workload** — Remaining task estimates plus timed calendar events and recurring-item durations for that day, shown against available work time when work hours are enabled
- **Capacity bar** — A bar under the workload figures showing how much of your available work time the planned workload occupies
- **Timed items** — A separate section (alarm icon) listing the day's tasks with a specific time, timed recurring task projections, and calendar events, each with its start time
- **Deadlines** — A section (flag icon) listing tasks whose deadline falls on that day
- **Calendar events** — Events from external calendars you've connected
- **Recurring task projections** — Instances of repeating tasks that will appear on that day

## Planning Vs Scheduling

The Upcoming uses **day-level planning**:

- Sets a task's due date (which day it's planned for)
- Does not set a specific time
- For today: the task appears in the Today View and uses today's ordering
- For future days: the task appears in that day's column in the Upcoming

**Scheduling** (time-specific) is different:

- Sets both a date and a specific time
- Tasks with a specific time are listed in their day's timed section in the Upcoming, with their start time, rather than among the day-level plans
- Creates entries in the Calendar view with start and end times

So you can plan a task for "Wednesday" in the Upcoming, or schedule it for "Wednesday at 2 PM" in the Calendar.

On wider screens, select **Inbox** above the days to show unscheduled, incomplete top-level Inbox tasks beside Upcoming. Drag a task to a day to plan it, or use its schedule button to choose a date without dragging. Close the panel to return to the full day view. The panel is available in the main Upcoming view; project-specific Upcoming remains scoped to that project.

## Planned but Not Completed

When you plan a task for a day but don't complete it:

- **For today** — The task stays in the Today View's ordering and appears in both the Today view and the Upcoming's today column
- **For future days** — The task remains in that day's column in the Upcoming
- **Automatic cleanup** — Days that have passed are automatically removed from the Upcoming
- **Deleted tasks** — Tasks you delete are automatically removed from planner days

## Recurring Tasks and Calendar Events

The Upcoming shows:

- **Recurring task projections** — Instances of repeating tasks on the days they'll occur, including the project and tags the created instances will have
- **Recurring tasks without times** — Shown as separate items in each day's column
- **Recurring tasks with times** — Appear in the day's timed section with their start time (and on the Calendar timeline)
- **Calendar events** — External calendar events merged into the same timed section

## How It Differs From Other Views

| Aspect               | Upcoming View                               | Today View / Project Views             |
| -------------------- | ------------------------------------------- | -------------------------------------- |
| **Organization**     | By date (day columns)                       | By project, tag, or today's list       |
| **Time specificity** | Day-level plans; timed items listed per day | Can have specific times via scheduling |
| **Focus**            | Forward-looking planning                    | Current work and execution             |
| **Recurring tasks**  | Shown as projections on future days         | Handled by repeat configuration        |
