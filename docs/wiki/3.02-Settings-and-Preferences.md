# Settings And Preferences

This page lists every option in the **Settings** dialog, grouped by category and
section in the order the app shows them, with each option's label, default and
a short description. Defaults are those of a new install; existing data keeps
its saved values. Platform differences are summarized in
[[3.05-Web-App-vs-Desktop]].

Options marked _(desktop)_ exist only in the desktop app, _(Android)_ only in the
Android app, and _(mobile)_ only in the iOS and Android apps. Options listed
under **More options** are hidden until you expand that part of the section.

## Using the Settings Dialog

Open **Settings** from the app navigation or with `Ctrl+,` (`Cmd+,` on macOS)
on a new installation. You can change **Go to settings** under Keyboard shortcuts. On
desktop, Settings opens in a centered dialog above the current workspace, with
the background dimmed and blurred. Close it with the close button, `Escape` or a
click outside the dialog to return to that workspace. On small screens, choose a
category from the list and use Back to choose another.

The categories are **General**, **Appearance**, **Tasks & planning**, **Time & focus**,
**Keyboard shortcuts**, **Sound**, and **Import & export**. **Account**
is a separate entry beside Settings (on a phone, a row at the end of the Settings list) and contains sync setup and status. Common choices appear first within each section; **More
options** reveals the rest. Each option has a question mark at the right edge.
Hover, focus, or click it to read help. Tooltips dismiss automatically when you
move away.

Search finds settings across categories by label, help text and setting name,
including collapsed options. Selecting a result opens its category and reveals
the matching option. Dependent options appear only when the option they depend
on is switched on.

**Plugins & integrations** is a row at the end of the Settings list on every screen size (on a phone together with **Account**).
It opens a separate window with **Installed** and **Discover** views. Search by
name, purpose, or author, and filter plugins separately from integrations.
Search and filters stay visible while browsing; large lists use pages of 24 items.
See [[2.21-Manage-Plugins]] for installation, configuration, permissions, and
the plugin trust model.

## General

### Language, dates & time

Choose a regional date/time format first, then refine task date labels and nearby
weekday labels. Live examples show the regional date/time and task label together.
These display preferences retain their existing saved keys.

- **Language** (default: follows the system language) — Language of menus and
  messages.

- **Regional date & time format** (default: **System default**) — Controls numeric
  date formatting and the 12/24-hour format of times the app _displays_. The ISO
  8601 option uses `YYYY-MM-DD` and a 24-hour clock. With ISO 8601 selected,
  weekday labels in Calendar, Habits, and Upcoming follow the app language. The
  System default option follows your browser or operating system regional
  locale; when formatting data for a locale is not available, dates fall back to
  British English (en-GB) formatting. The same day/month order is used to read
  numeric dates typed with short syntax: `@3/1` is 3 January with a day-first
  format and March 1 otherwise ([[3.04-Short-Syntax]]).

  This setting does not affect **time entry fields** — the time input in the
  schedule and deadline dialogs is a native browser control, and browsers render
  it in the clock format of the browser or operating system UI language, which a
  web page cannot override. On a 12-hour system that field shows `02:00 PM` even
  with a 24-hour locale selected here; the stored time is still correct.

- **Task date labels** (default: **3-Dec (abbreviated month)**) — Choose
  **Numeric (follow Regional date & time format)**, **3-Dec (abbreviated month)**
  (day and localized abbreviated month), or **December 3rd (English)** (full
  English month and ordinal day). This applies outside the weekday window, or
  whenever weekday labels are disabled. The preferences update task-row labels
  immediately and are saved across restarts. Clock formatting and numeric date
  entry continue to use **Regional date & time format**.
- **Show weekdays for the next seven days** (default: on) — Task due-date and
  deadline labels keep **Today**, then show weekday names for the following
  seven calendar days, including the same weekday next week. The configured
  start of day applies to timed tasks; today's timed tasks keep their time
  label.

More options:

- **First day of the week** (default: follows the system locale) — First day in
  calendar weeks.

### Startup & interface

The section help explains how to check Windows notification settings when
desktop notifications do not appear.

- **Default start page** (default: **Today**) — The view that opens when the app
  starts: Today, Upcoming, Calendar or Boards (each only while its feature is
  switched on), or any project shown in the sidebar, including the Inbox.

More options:

- **Show the number of tasks due today or overdue on the app icon (desktop)**
  (default: off) — Counts incomplete task rows in active projects with a
  scheduled date today or earlier. A subtask counts separately when its parent
  is absent from the same Today or overdue group; nested children do not add
  another count. Timed tasks under Later Today count too, so the badge includes
  both today's tasks and overdue rows. The Today sidebar uses the same total,
  including Later Today, and its tooltip breaks it down as “8 today · 7 overdue”.
  This count also works when the optional desktop badge is disabled.
  The configured start of the day applies.
  Zero clears the badge. Windows uses a dark gray circle with smooth, semibold white
  numbers, displaying up to `99+`; macOS uses the Dock badge
  and requires notification permission. Linux support depends on the launcher.
- **Confirm before exiting the app without finishing day first** _(desktop)_
  (default: on) — Asks before the desktop app closes while today has not been
  finished. The web app shows **Confirm before exiting the app** instead
  (default: off), which asks before you leave or reload the page.
- **Minimize to tray (desktop only)** (default: off) — Keeps the desktop app
  running in the system tray when you close its window.
- **Enable local REST API (desktop only)** (default: off) — Starts a localhost
  HTTP API on `http://127.0.0.1:3876` for local scripts and tools. Every request
  except `GET /health` must include the generated access token as
  `Authorization: Bearer <token>`. The token is shown below this setting as
  **Access Token** and can be regenerated with **Regenerate Access Token**,
  which invalidates the previous token immediately. This is a
  breaking change for older API clients that used the API without authentication.
  The setting is stored on this computer only and is not synced; after updating
  from a version where it was synced, switch it on again on each computer that
  should serve the API (the access token stays the same). The panel shows
  whether the API is running, or why it is not. See [[3.01-API]] (Local REST API).
- **Enable assistant access (MCP, desktop only)** (default: off) — Lets an AI
  assistant on this computer (for example Claude Code or Codex) use
  Ultra Tasks through the Model Context Protocol at
  `http://127.0.0.1:3876/mcp`, limited to the permissions chosen below it: read
  tasks, also read task notes, and add new tasks to the Inbox (all off by
  default). The access key is shown once when generated; replacing it
  disconnects assistants using the old one. The panel includes a ready-made
  Claude Code command and a generic client configuration. Stored on this
  computer only and not synced. See [[3.01-API]] (Assistant Access).
- **Automatically check for new versions (desktop only)** (default: on) — Once a
  day the desktop app asks the GitHub releases API whether a newer version has
  been published and shows a dismissible notice linking to the download page.
  No personal data is sent, nothing is installed automatically, and each
  version is announced at most once. The setting (and a manual **Check for
  updates** link in the settings footer) only appears on builds without their
  own update channel; store and Snap builds, which Ultra Tasks does not
  publish, would update through their stores instead.
- **Start time of the next day** (default: `00:00`) — Until this time the app
  still treats the previous day as today, for example in Today and for
  repeating tasks. Useful when you work past midnight.
- **Disable all animations** (default: off) — Turns off interface animations.
- **Vertical action bar on the side (experimental)** (default: off) — Moves the
  header action buttons into a vertical strip on the right edge of the window.
  Desktop only.
- **Disable celebrations (confetti)** (default: on) — Turns off confetti
  celebrations: on the daily summary, on project completion, when a focus
  session ends and when a habit reaches its goal. Untick it to turn the
  celebrations on. Installs that saved this setting before
  the default changed keep their previous choice.
- **Show productivity tip on app start a little longer** (default: off) — Keeps
  the productivity tip shown at startup visible for longer.
- **Show current countdown in the tray / status menu (macOS only)** (default:
  on) — Shows the active timer or countdown in the desktop status menu title.
  When this is disabled and current-task display is enabled, the title can show
  the current task instead.
- **Use custom title bar (Windows/Linux only)** _(desktop)_ (default: on) —
  Draws the app's own window title bar. Requires a restart. Not offered on
  GNOME with Wayland, where the custom title bar is always off.

### App features

Switch off features you don't use; switching a feature off hides it and stops
what it does, and its data stays.

- **Upcoming** (new installs: on) — Plan tasks across the coming days.
- **Boards** (new installs: off) — Kanban-style boards that group tasks by tag,
  project or done state.
- **Project notes** (new installs: on) — A side panel for notes that belong to
  the current project or tag.

More options:

- **Schedule** (new installs: off) — A calendar view of your days and weeks
  for scheduling and time-blocking tasks. The Calendar view replaces the former
  calendar side panel.
- **Habits** (new installs: off) — Track recurring habits with daily check-ins.
- **Stopwatch time tracking** (new installs: on) — The play button that tracks
  time on the current task.
- **Focus mode** (new installs: off) — A full-screen view for one task at a time
  with a Pomodoro, Flowtime or countdown timer.
- **Finish day** (new installs: off) — The button below today's tasks that opens
  the daily summary and archives done tasks.
- **Sync button** (new installs: on) — The header button that starts a sync and
  shows the sync status.
- **Search** (new installs: on) — Search across tasks, archived tasks and notes.
- **Support us page** (new installs: on) — A **Help** menu entry with ways to contribute
  to Ultra Tasks. Not offered in the iOS and macOS apps.

- **Defaults on a new install** — The new-install values above apply only to a
  fresh install. Existing data keeps its own settings, and data saved before a
  feature switch existed treats that feature as on. The defaults themselves are
  never saved or synced, and changing a switch here syncs only that switch, so a
  new device does not turn features off on your other devices. A new device
  joining an account whose feature settings were never changed can therefore
  show fewer features until you switch them on there.
- **Switching a feature off where you see it** — Sidebar entries for Upcoming,
  Calendar, Boards, and Habits offer **Disable feature** in their menu; the play
  button in the header offers the same for time tracking (right-click, or long
  press on touch devices, while there is a task to track).

### Clipboard images

Images pasted into notes are stored separately from your task data.

- **Manage Stored Images** (web app) — **Manage Images** lists the stored images

## Appearance

All twelve presets remain visible, including Nord Polar Night, Nord Snow Storm,
Dracula, Catppuccin, Everforest, Arc, Zen and Velvet. Their light and dark colors
use the shared contrast normalizer; no third-party layout overrides are loaded.

- **Dark mode** (default: **System**) — **System**, **Light** or **Dark**.
  System follows the device's light or dark appearance.
- **Color palette** — Always visible: choose one of the twelve presets, or edit the
  **Background**, **Cards and panels**, and **Accent** colors of the mode that
  is currently shown, with a live preview. Text contrast is automatic.
  **Reset colors** restores both default palettes. Light and dark palettes are
  separate and saved on this device. CSS themes, project background images, and
  manual hue/contrast controls are no longer applied. See [[3.09-Theming]] for
  details.
- **Glass appearance** (default: on) — Frosted navigation, header, task detail
  panel and bottom bar with a slight, blurred show-through: the desktop in the
  macOS and Windows 11 desktop app, otherwise the background image or a
  gradient from your colors. Off gives solid surfaces. Saved on this device and
  not synced. See [[3.09-Theming]].
- **Background image** — Shown only while Glass is on, and not in the macOS and
  Windows 11 desktop app. **Choose image** sets a file for **Light mode** or
  **Dark mode** (one image serves both when only one is set); **Remove** goes
  back to the gradient. Images are reduced to at most 256 pixels and about
  24 KB, shown blurred, and sync with your settings.

### Tasks

- **Confirm before deleting tasks** (default: on)
- **Default project** (default: **Inbox**) — New tasks go here when you create
  them without selecting another project.

More options:

- **Automatically add worked-on tasks to today** (default: on) — Adds a task to
  Today when you start tracking time on it.
- **Automatically mark parent task as completed when all subtasks are
  completed** (default: off)
- **Show current task in the tray / status menu (macOS/Windows only)** (default:
  on) — Allows the desktop tray or status menu to show the active task. On
  macOS, the current countdown setting takes priority while it is enabled.
- **Enable Markdown formatting in task notes** (default: on) — Notes are edited
  in an editor that renders markdown as you type, showing the plain syntax only
  on the line you are editing. Turning this off replaces that editor with a

  a priority show nothing.
- **Task description template** (default: three prompts — _How can I best
  achieve it now?_, _What do I want?_, _Why do I want it?_) — Starting notes
  offered in focus mode for a task without notes. The task pane starts with an empty Description editor.

### Idle handling

Idle detection works in the desktop app. The section is not shown in the
Android app. In the web app the idle options are not available; the section only
shows a note about the browser extension (see [[3.05-Web-App-vs-Desktop]]).

- **Enable idle time handling** (default: on) — When you return after being
  away from the computer, a dialog asks how to account for that time. See
  [[4.17-Idle-Time]].
- **Trigger idle after X** (default: 5m) — Shown while idle time handling is on.
  How long you need to be away before the idle dialog is shown. Must be at
  least **1 minute**: the desktop app never reports shorter idle periods, so
  anything lower is rounded up to about a minute rather than honoured. Idle is
  sampled every 30 seconds, so the dialog can appear up to that much after the
  threshold is reached.

More options (shown while idle time handling is on):

- **Only trigger idle time dialog when the current task is selected** (default:
  off) — Only show the idle dialog while a task is being tracked.
- **Suppress idle dialog during focus mode sessions** (default: on) — The idle
  dialog does not appear while a focus mode session is running. Useful when you
  are working at the computer without keyboard or mouse input (e.g. reading,
  studying, or writing exams).

## Import & export

### Import

Choose **Import from** to reveal platform-specific export instructions. Sources are Ultra Tasks JSON,
compatible Super Productivity JSON, Todoist, TickTick, or a backup URL.
Native backup restore replaces all current data after confirmation; see
[[2.02-Restore-Data-From-Backup]]. Todoist and TickTick import CSV files directly
inside Settings, with project/task counts before **Import tasks**; see [[2.20-Import-from-Todoist]] and [[2.22-Import-from-TickTick]].

### Export

**Ultra Tasks JSON** downloads a complete backup. **Encrypt this export** is off
by default; enabling it asks for a passphrase and confirmation before downloading.

### Recovery

- **Compress Archive** — Shrinks the archive: clears notes older than a year and
  issue fields of archived tasks, and deletes archived subtasks after adding
  their time to the parent. A dialog lists what will be removed. The change
  syncs to all devices and cannot be undone.
- **Export Data (anonymized)** — Exports diagnostic data for a private report to
  the Ultra Tasks maintainer. Inspect it before sharing; see [[3.06-User-Data]].
- **Browse backups** — Lists the backups stored on this device, including
  recovery points made before sync or an import replaced your data, and
  restores one after confirmation.

### Automatic backups

Desktop and Android only.

- **Enable automatic backups** (default: on) — Creates local backups
  automatically. The desktop app shows the backup folder.
- **Clear all** — Opens the backup list and a destructive confirmation. It removes automatic backup files and local recovery points on this device, including the Undo copy, without deleting current tasks or manual exports elsewhere. Automatic backups can create new copies afterward. The same action is available in **Browse backups**; a partial failure refreshes the list and reports remaining copies.
- **Maximum backup files** _(desktop)_ (default: 51) — Limits how many automatic
  backup JSON files are kept in the `backups/` folder; older files are deleted
  once the limit is exceeded.
- **Restore latest automatic backup** _(Android)_ — Restores the latest usable
  automatic backup and replaces the current local data after confirmation. A
  **Last backup** line shows when the latest backup was made.

Native exports are complete JSON backups with timestamp, lastUpdate,
crossModelVersion and data, including archives. **Encrypt this export** wraps
those exact JSON bytes in a versioned ultra-tasks-encrypted-backup envelope using
the existing Argon2id + AES-GCM implementation. The file passphrase is independent
of sync encryption. Import asks for it before restoring through the normal
validation and recovery path. Keep the passphrase separately: it cannot be
recovered. Plain exports retain their existing JSON format.

The importer dropdown provides Ultra Tasks and compatible Super Productivity JSON
backups, Todoist CSV, TickTick CSV, and URL import. The CSV importers are built in
and do not require enabling or installing a plugin. Native restore replaces the workspace rather than merging it.

Keep automatic backups and bounded local recovery history: sync can propagate a
mistake, while recovery copies let you go back. A device-local backup does not
protect against losing that device, so occasionally keep a manual export elsewhere.

## Project And Tag Settings

These settings are not in the Settings dialog. Open them from a project's or
tag's context menu (**Settings**). Today uses the tag settings dialog and the
Inbox the project settings dialog. Changes apply immediately; **Cancel** reverts
them.

Project settings:

- **Project Name** — Required.
- **Icon** — Emoji are allowed.
- **Enable Project Backlog** — Adds a separate backlog list to the project.
- **Hide project from sidebar** — Removes the project from the sidebar project
  list. The project stays active: its tasks can still appear in cross-project
  task views such as Today, Upcoming, Calendar, Boards, and Search. The sidebar
  visibility menu remains the place to show the project again; project short
  syntax does not match hidden projects.
- **Theme color** — The project's color, used for its icon and labels.

Tag settings:

- **Tag Name** — Required.
- **Icon** — Emoji are allowed.
- **Tag color** — The color of the tag's labels on tasks.
- **Theme color** — The color of the tag's icon in the sidebar and page title.
  If not set, the tag color is used.

Project and tag colors do not change the app palette; that is set under
**Appearance** ([[3.09-Theming]]).

## Recurring Task Settings

In a task's repeat settings, expand **Advanced configuration** and choose a **Priority** (None, Low, Medium, or High). New occurrences use this default. When a task becomes recurring, its current priority is copied into the repeat settings.

Changing the repeat priority offers **Update all instances** or **Only future tasks**. Choose **None** to clear the series default. Changing priority from an individual task's context menu affects that occurrence only; use the repeat settings to change the series.

## Phone Bottom Navigation

On narrow screens (below 600px) a bar at the bottom holds Today, a second
destination, the add-task button, the side panels and the menu. The second
destination is **Upcoming** by default. Long-press it (or right-click it, or
press the context-menu key while it is focused) to choose **Upcoming**,
**Inbox**, **Boards**, **Calendar**, **Search** or a page an enabled plugin
adds to the side menu instead; a normal tap still opens it. Only destinations
whose feature is switched on in App features are offered. If the chosen one is
switched off or its plugin is removed, the button goes back to Upcoming (a
plugin choice shows Upcoming until the plugin has loaded); if Upcoming is
switched off too, the button is hidden. The choice is stored on the device only
and is not synced, so each phone keeps its own.

## Project, Tag, Today, And Inbox Settings

Task lists use a bounded, centered column within the available workspace. The
summary, section headers, task rows and add-task row share that column. Opening
a side pane recenters the list in the remaining space; on narrow screens the
list fills the width between the normal page gutters.

### Basic Settings

- **Enable Project Backlog** — Adds a separate backlog list to the project.
- **Hide project from sidebar** — Removes the project from the sidebar project list. The project stays active: its tasks can still appear in cross-project task views such as Today, Upcoming, Calendar, Boards, and Search. The sidebar visibility menu remains the place to show the project again; project short syntax does not match hidden projects.

### Theme

Choose a preset or edit the background, cards/panels, and accent colors under
**General → Appearance**. Text contrast is automatic. Light and dark palettes
are separate and saved on this device. CSS themes, wallpapers, and manual
hue/contrast controls are no longer applied. See [[3.09-Theming]] for details.

## Built-in Icon Meanings

Today uses a calendar-day symbol. Upcoming uses an editable calendar, Calendar a
calendar with time columns, and Notes a document. A clock marks a time of day,
an hourglass an estimate, a stopwatch tracked time, an alarm a reminder, and a
flag a deadline. Removing a planned date uses a calendar with a cross; it does
not stop the task timer. The date picker keeps today's day number visible.

Built-in legacy Today, priority-tag and counter defaults display the updated
symbols without rewriting saved data. Other user-selected icons remain as
chosen. Android and iOS Today launcher shortcuts also use a calendar; Android
widget completion controls use rounded checkboxes.
